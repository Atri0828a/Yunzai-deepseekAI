# deepseekAI for Yunzai

### 介绍
调用deepseek api进行AI对话  
**强烈建议下载与使用该文件：deepseekAI.js，因为功能更加完善**，目前我仅对deepseekAI.js进行维护 ,deepseekAI-1.js暂时废弃（仅用作古早版本代码备份），deepseekAI-2.js现在仅用作新版本日志记录，以兼容旧版本插件的版本查询功能
欢迎查看与下载作者更多的发癫小插件：[**详情点击**](https://gitee.com/atri0828a/Yunzai-plugins)  
咕了这么久的识图功能我终于写好了

### 安装方式

1.下载deepseekAI.js文件放入plugins/example  
2.打开文件根据注释进行修改与配置。有问题请根据注释解决。  
3.首次安装需要依赖openai和axios，可能会需要额外安装其它依赖，下面是openai依赖的安装指令，其它的同理  
喵崽
```  
pnpm i openai -w
```  
trss崽  
```  
pnpm i openai
```  


### 功能/指令

| 指令 | 用途 |
|:-------:|:-------:|
| #ds帮助 | 显示帮助图片 |
| 消息中包含预设的关键词或 @机器人 | 触发对话 |
| 带图片一起发送 | 自动识图（图像理解开启时生效，<br>需要支持图像的模型，如 deepseek-flash） |
| #ds开始对话 / #ds结束对话 | 进行连续的无需关键词的私聊对话<br>（30 分钟无对话自动结束） |
| #ds清空对话 | 清除本次对话记录（需管理员） |
| #ds群聊分离(开启/关闭/状态) | 选择共用对话历史还是分开（需管理员） |
| #ds设置预设 [内容] | 临时修改自己想要的AI人格（需管理员） |
| #ds清空预设 | 清除临时修改的预设<br>并自动使用系统原预设（需管理员） |
| #ds查看预设 | 查看当前的预设是什么 |
| #ds选择预设 [数字] | 选择不同的系统预设（需管理员） |
| #ds存储对话 [名称] | 保存本次对话到系统中<br>名称可省略（需管理员） |
| #ds查询对话 | 查看保存的历史对话（最多显示 20 个） |
| #ds选择对话 [文件名] / #ds删除对话 [文件名] | 选择/删除某个历史对话<br>可省略 .json 后缀（需管理员） |
| #ds模型 | 查询当前可用的模型并编号列出<br>回复序号即可切换，回复 0 恢复默认（需管理员） |
| #ds思考模式(开启/关闭/状态) | 切换本会话的思考模式，默认关闭（需管理员） |
| #ds思考强度(low/high/max/状态) | 设置思考强度，越高越聪明也越慢越贵（需管理员） |
| #ds图像理解(开启/关闭/状态) | 带图消息是否交给模型识别，默认开启（需管理员） |
| #ds重置设置 | 清空本会话全部配置（含自定义人格）恢复默认<br>不影响对话历史（需管理员） |
| #ds余额查询 | 查询API的余额 |
| #ds查询版本 | 查询是否有新版代码 |
| #ds(黑名单/白名单)(添加/删除)12345 | 增删黑白名单（需管理员，白名单用户不可用） |
| #ds拉黑群 [群号] / #ds解除拉黑群 [群号] | 拉黑/解除拉黑群聊，被拉黑的群只响应 #ds帮助<br>不填群号=当前群（仅主人） |

**几点说明**

- 预设就是 AI 的人格
- 未保存的对话会在 30 分钟后自动结束并清空（可在代码中手动修改这个时长）
- 目前最多保留 30 条历史记录、单条消息最多 10000 个字符（都可在代码开头修改）
- ！对话历史的优先级高于预设，所以改完预设记得先清空一下对话历史 ！
- 指令里的空格可有可无：`#ds思考模式开启` 与 `#ds思考模式 开启` 效果相同
- 思考模式下 `temperature` 会被官方忽略，先 `#ds思考模式关闭` 才会生效
- 图片不会写入对话历史，只在历史里保留一个 `[图片]` 占位
- 已经能识别你**回复（引用）**的那条消息，会把它作为上下文一起发给模型；
- 模型 / 思考模式 / 图像理解 / 人格等设置按"会话"保存（私聊、每个群各自一份），存放在 `resources/deepseekai/customPrompts.json`，**重启云崽后依然生效**；想还原默认用 `#ds重置设置`


### 相关报错

1.帮助图片无法生成/puppeteer启动失败：按代码内提供的备用帮助方案解决    
2.执行完依赖安装命令之后，重启依然显示缺依赖：这不是我的问题喵~ 自己想办法解决喵~ （可能是nodejs的问题吧）  
3.消息包含关键词却无法触发AI对话：检查你的触发关键词是否和你在云崽自己的配置文件中的别称相同，云崽会把别称裁掉再把消息传入，导致无法触发
